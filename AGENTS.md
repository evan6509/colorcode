# Agent instructions

- Treat `main` as the reviewed stable baseline; all future development and regular commits must go on `codex/development`.
- Merge into `main` only with explicit user approval.
- Make regular, small, logical local commits of completed, verified work; do not leave long stretches of work uncommitted.
- Do not commit generated builds, caches, secrets, or signing keys.
- Preserve existing user work and unrelated changes.
- Never push or publish without explicit user authorization.
- Never claim tests or device verification were performed unless you actually performed them.
